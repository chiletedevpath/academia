# Fullstack con Java

Proyectos desarrollados en el curso **Fullstack con Java** de Tecsup.

El conjunto muestra práctica en backend, frontend, persistencia y consumo de servicios. Cada proyecto se conserva como evidencia académica con su propio alcance y límites.

## Proyectos

| Proyecto | Enfoque | Tecnologías | Estado | Acceso |
|---|---|---|---|---|
| SUNAT Consulta | Backend e integración externa | Java, Spring Boot, OpenFeign, H2 | Tests ejecutados correctamente | [Ver proyecto](sunat-consulta/) |
| Backend Final Exam | Backend y microservicios | Java, Spring Boot, PostgreSQL, Dockerfile | Requiere configurar datasource para pruebas locales | [Ver proyecto](backend-final-exam/) |
| CRUD React Productos | Frontend web | React, Vite, JavaScript, Fetch API | Requiere instalar dependencias para build local | [Ver proyecto](crud-react-productos/) |

## Enfoque de aprendizaje

- Construir APIs REST con Spring Boot.
- Separar controladores, servicios, repositorios, DTO y entidades.
- Consumir APIs externas desde backend.
- Conectar un frontend React con una API.
- Usar variables de entorno para configuración local.
- Reconocer deuda técnica cuando una entrega académica necesita ajustes para validación reproducible.

# Academia

**Academia** reúne proyectos formales desarrollados durante mi formación en UTP, Tecsup y otros espacios de estudio.

Este repositorio conserva evidencia técnica con contexto: qué se construyó, en qué curso nació, qué conceptos se aplicaron y qué límites tiene cada entrega. No funciona como portafolio profesional final; funciona como historial académico ordenado dentro del ecosistema Chilete DevPath.

## Cómo leer este repositorio

- `utp/` conserva proyectos de la carrera de Ingeniería de Sistemas e Informática.
- `tecsup/` conserva prácticas y evaluaciones técnicas complementarias.
- Cada proyecto debe leerse como evidencia de aprendizaje, no como producto comercial.
- Los README documentan contexto, alcance, ejecución, estado y límites verificables.
- Los proyectos con marcas, contextos colaborativos o datos sensibles requieren criterio editorial antes de publicarse fuera de GitHub.

## Relación con Chilete DevPath

Dentro del ecosistema, `academia` funciona como evidencia formativa. La ruta progresiva de estudio vive en [`aprendizaje`](https://github.com/chiletedevpath/aprendizaje), la entrada visual está en la [web oficial](https://chiletedevpath.com/) y la selección profesional futura se trabajará en [`portafolio`](https://github.com/chiletedevpath/portafolio).

## Criterio de publicación

Los proyectos UTP se publican como evidencia académica propia. No representan publicaciones oficiales de la universidad ni productos empresariales finales. Cuando un proyecto usa dominios de negocio o nombres comerciales, debe mantenerse con contexto académico claro y datos ficticios o autorizados.

## Qué revisar

- README del proyecto para comprender objetivo, alcance y ejecución.
- Código fuente o scripts para validar la implementación.
- Estado y mejoras futuras para distinguir la entrega académica de una evolución posterior.
